🏠 헤이홈

헤이홈 앱에서 만든 레시피(원터치)를 그대로 불러와 모드에 넣습니다. 처음 한 번은 이메일 인증번호 확인이 필요합니다.

비밀번호는 이 폰 안에서만 암호화해 보관하고, 로그인이 풀렸을 때 다시 로그인하는 데에만 씁니다.

🎙 음성 · 빠른 설정

제미나이에게 “티비 켜기 열어 줘”라고 말하면 위에서 고른 모드가 바로 실행됩니다. “티비 켜기”, “티비 끄기”는 이 앱이 홈 화면 앱 목록에 함께 만들어 두는 실행 버튼입니다.
빠른 설정 타일은 알림창을 내린 뒤 ✏(편집)에서 “TV 한번에”를 끌어다 놓으면 됩니다.

도움말

• 헤이홈 IR 리모컨은 전원 버튼이 켜기·끄기를 번갈아 하는 경우가 많습니다. 단계의 조건을 “구글 TV가 꺼져 있을 때만”으로 두면 이미 켜져 있을 때 TV가 꺼지는 일을 막을 수 있습니다.
• 레시피 안의 타이머는 헤이홈 서버에서 진행되므로, 레시피 다음 단계 앞에 “기다리기”를 넣어 시간을 맞춰 주세요.
• 워치에서는 타일이나 앱에서 모드를 누르면 폰이 대신 실행합니다.
