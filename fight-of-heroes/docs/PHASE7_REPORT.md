# PHASE 7 보고서: 전투 이어 하기, 밸런스 측정 확대

## 전투 이어 하기

- 진행 중인 전투를 `user://save_battle.json` 에 저장하고, 메인 메뉴의 "이어 하기" 버튼으로 다시 엽니다. 버튼 아래에는 저장한 경기 시간과 점수가 나옵니다.
- **저장하는 때:** 경기 시간 15초마다 자동으로, 앱이 백그라운드로 가거나 화면이 꺼질 때, 일시정지 메뉴의 "저장하고 처음 화면"을 누를 때.
- **저장하는 내용:** 경기 설정, 경기 시간, 킬 점수, 연속 처치, 피해 기록, 영웅마다 위치·체력·마나·레벨·경험치·골드·스킬 포인트·스킬 단계·쿨타임·아이템 칸·상태 효과·부활 남은 시간·K/D/A, 캠프마다 남은 리스폰 시간·살아 있는 몬스터의 위치와 체력, 최종 보스까지 남은 시간.
- **저장하지 않는 내용:** 투사체, 위험 지역, 소환수처럼 몇 초 안에 끝나는 것과 AI 의 순간 판단입니다. 보스의 분노 단계는 불러온 뒤 체력을 보고 다시 판정합니다.
- 불러온 전투는 일시정지한 채로 시작하므로, "계속하기"를 눌러야 경기가 이어집니다.
- 경기가 끝나면 저장한 전투를 지웁니다. 새 게임을 시작하면 저장한 전투가 사라진다고 먼저 묻습니다.
- 관전(AI 끼리)과 시험용 자동 진행 경기는 저장하지 않습니다.
- 저장 형식이 맞지 않거나(버전, 없는 영웅·맵, 영웅 구성 불일치) 파일이 깨져 있으면 되돌리지 않고 버튼도 띄우지 않습니다.
- 코드: `scripts/save/battle_snapshot.gd` (저장·되돌리기), `SaveManager.save_battle/load_battle/clear_battle`, `GameManager.resume_battle/leave_battle`, `battle_scene.gd` 의 자동 저장.

## 밸런스

- **측정 도구:** `tools/balance.sh <판 수> <프로세스 수>` 가 측정을 여러 프로세스로 나눠 돌리고 결과를 합칩니다. 작업 환경(CPU 4개)에서 120판이 약 25분 걸립니다. 각 판의 영웅 구성은 판 번호로 정해지므로 조정 전과 후를 같은 구성으로 비교합니다.
- PHASE 6 의 40판 측정(성녀 6%, 성기사 75%)은 영웅마다 17~31판뿐이라서 오차가 컸습니다. 120판(영웅마다 65~81판)으로 다시 측정한 결과는 38~65% 였습니다.
- 조정: 검성 공격력 62→59, 궁극기 피해 180/280/380→160/250/340. 성기사 공격력 60→63, 최대 체력 700→730, Q 피해 70~175→85~205. 빙결술사 최대 체력 540→560. 성녀 최대 체력 580→600.

| 영웅 | 조정 전 (120판) | 조정 후 (120판) |
|---|---|---|
| 검성 | 65% | 49% |
| 암살자 | 55% | 48% |
| 화염술사 | 54% | 56% |
| 용기사 | 52% | 60% |
| 엘프 궁수 | 51% | 46% |
| 소환술사 | 49% | 53% |
| 무투가 | 49% | 60% |
| 빙결술사 | 43% | 48% |
| 성녀 | 42% | 42% |
| 성기사 | 38% | 40% |

전체 범위가 38~65% 에서 40~60% 로 줄었습니다. 측정 결과는 `docs/phase7/balance_before.txt`, `balance_after.txt` 에 있습니다. 두 측정 모두 스크립트 오류는 0개였습니다.

## 테스트 결과

- 자동 시험 120개 모두 통과, 스크립트 오류 0개 (`docs/phase7/test_result.txt`).
- 새 시험 (`tests/unit/test_resume.gd`): 20초 진행한 전투를 JSON 으로 저장했다가 새 전투 화면에 되돌려 경기 시간·킬 점수·레벨·골드·아이템·스킬 단계·쿨타임·상태 효과·능력치·체력·위치·쓰러진 영웅과 부활 시간·몬스터 수·최종 보스 시간이 같은지 확인하고, 되돌린 뒤 경기가 계속 진행되는지 확인합니다. 저장 파일·메인 메뉴 버튼, 자동 저장과 경기 종료 시 삭제, 잘못된 저장 내용 거부도 시험합니다.
- **전체 흐름 시험**에 이어 하기를 추가했습니다: 사람이 조작하는 경기를 시작 → 3초 뒤 "저장하고 처음 화면" → 메인 메뉴에 이어 하기 버튼 확인 → 이어 하기 → 경기 시간이 그대로이고 일시정지 상태인지 확인 → 경기 종료 → 저장한 전투가 지워졌는지 확인.
- 화면 캡처: `docs/phase7/main_menu_resume.png` (이어 하기 버튼), `docs/phase7/battle_resumed.png` (불러온 전투, 일시정지 상태).
