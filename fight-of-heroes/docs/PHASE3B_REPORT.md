# PHASE 3 보완: 맵 개편과 역할 AI, 스킬 쿨타임 버그 수정

사용자 의견("아군이 굳이 따라다닐 필요가 있나, LoL 처럼 역할이 있으면 좋겠다", "파오케처럼 중앙에 미니언이 짧은 주기로 소환되고, 던전은 11·1·5·7시와 12·6시에", "스킬이 누르는 대로 무한으로 나간다")을 반영했습니다.

## 1. 스킬 쿨타임·마나 버그 (APK 에서만)

- **원인:** `SkillData.mana_cost`·`cooldown` 의 기본값을 `= []` 로 적었는데, Godot 이 APK 로 내보낼 때 이 두 배열을 기본값으로 보고 빼 버렸습니다. 내보낸 패키지 안에서 스킬 21개의 마나·쿨타임 배열이 모두 비어 있어, 쿨타임 0·마나 0 으로 무한히 쓸 수 있었습니다. 편집기와 시험에서는 원본 파일을 읽으므로 드러나지 않았습니다.
- **수정:** 기본값을 `PackedFloat32Array()` 로 바꿨습니다. 캐시 없이 처음부터 내보내 수정 전에는 오류 42건, 수정 후에는 0건임을 확인했습니다.
- **재발 방지:** `DataRegistry.validate()` 가 스킬·영웅·몬스터·맵 데이터를 검사합니다. CI 는 Linux 패키지를 내보내 `--selfcheck` 로 실행해, 내보낸 결과물에서 같은 검사를 합니다. 시험에도 "Packed 배열 기본값을 [] 로 적지 않았는지" 검사를 넣었습니다.

## 2. 새 맵 "영웅의 계곡" (`data/maps/valley_01.tres`, 4200×2600)

| 위치 | 내용 |
|---|---|
| 9시 / 3시 | 블루 / 레드 기지(우물) |
| 중앙 | 15초부터 30초마다 떠돌이 고블린 3마리 소환, 최대 12마리까지 쌓임(먼저 와서 잡는 팀이 이득). 10분에 최종 보스 고대 흑룡 |
| 11·7시 (블루 쪽), 1·5시 (레드 쪽) | 벽으로 둘러싼 던전. 입구는 중앙 쪽. 안에 바위 골렘(정예)과 늑대 무리 |
| 12시 / 6시 | 큰 던전: 숲의 수호정령 / 용암 거인 |

- 맵은 중앙 기준 점대칭입니다. 캠프의 `wave_interval`·`wave_max` 로 주기 소환을 설정합니다.
- 맵 검사: 캠프와 시작 지점이 장애물 안이나 맵 밖에 있지 않은지 확인합니다.
- 이전 맵(`arena_01`)은 시험용으로 남겼습니다.

## 3. 역할 AI (아군이 플레이어를 따라다니지 않음)

| 역할 | 하는 일 |
|---|---|
| 돌격 (검성 선호) | 중앙 고블린을 잡고, 평균 레벨이 상대보다 1 이상 높으면 상대 진영 던전에 쳐들어감. 없으면 자기 진영 던전 |
| 사냥꾼 (엘프 궁수 선호) | 자기 진영 던전, 그다음 중앙 |
| 지원 | 체력이 절반 아래인 아군, 없으면 돌격 AI 곁을 지킴(돌격 AI 가 없으면 플레이어 곁). 2000 거리 안에서 공격받는 아군에게 달려감 |

- 경기 시작 때 팀 안에서 역할이 겹치지 않게 나눕니다. 플레이어 영웅의 선호 역할은 먼저 뺍니다.
- **팀 계획(AIManager):** 보스 도전과 "모여"는 팀 단위로 정합니다. AI 팀은 조건(2명 이상, 평균 체력 50% 이상, 중립 6레벨·최종 8레벨)이 맞으면 보스에 도전합니다. 플레이어 팀은 플레이어가 보스를 공격하기 시작하면 아군이 합류합니다.
- **"모여!" 버튼:** 오른쪽 위 일시정지 아래. 누르면 아군 AI 가 15초 동안 플레이어 자리로 모입니다(컴퓨터에서는 G 키).
- 시작 직후 길찾기 맵이 덜 준비돼 영웅이 맵 모서리로 걸어가던 문제를 고쳤습니다.
