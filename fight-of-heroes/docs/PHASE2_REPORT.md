# PHASE 2 완료 보고 (3대3 전투)

## 구현한 기능

| 구분 | 내용 |
|---|---|
| 팀 구성 | 3대3. 플레이어 영웅을 고르면 아군 2명·적군 3명은 무작위(같은 영웅 중복 가능). 처음 화면에 "AI끼리 관전하기" |
| 팀 AI | 팀 리더(플레이어, 없으면 살아 있는 첫 영웅). 나머지는 리더 뒤 양옆으로 FOLLOW. 리더는 아군이 모이면 MOVE 로 맵을 돌며 적을 찾음 |
| 아군 지원 | 최근 2초 안에 아군을 때린 적을 우선 공격. 플레이어 팀 AI 는 플레이어에게서 800 이상 먼 적은 쫓지 않음 (지원 대상은 예외) |
| 집중 공격 | 어려움 난이도에서 팀이 같은 대상(아군 가까이 있는, 체력이 낮은 적 영웅)을 함께 노림 |
| 후퇴 판단 | 이기고 있으면(가까운 적의 체력 비율이 더 낮으면) 물러나지 않고, 후퇴 중에도 쫓아온 적이 약하면 돌아서 싸움. 근처 아군이 많으면 더 버팀 |
| 우물 | 자기 우물에서 회복, 상대 우물에 들어가면 초당 최대 체력 20% 피해. AI 는 상대 우물 안까지 쫓지 않음 |
| 처치 규칙 | 마지막 일격 = 처치, 최근 10초 안에 피해를 준 적 영웅 = 도움. 출처 없는 피해로 죽으면 최근에 때린 적이 처치 |
| 이동 | 같은 팀 유닛끼리 겹치지 않게 밀어냄 (기절 중에는 밀리지 않음) |
| 화면 | 위쪽 양옆에 아군·적군 상태(체력 고리, 사망 시 부활 초), 미니맵(지형·영웅·카메라 범위), 처치 알림(팀 이름, 도움 수) |
| 설정 | 목표 킬 10 / 15 / 20 / 30 (처음 화면, 저장됨) |
| 버그 수정 | "최근에 맞았는지" 같은 판단을 현실 시계가 아니라 게임 시간(물리 프레임)으로 계산 |

## 테스트 결과

- 자동 시험 52개 모두 통과, 스크립트 오류 0개 (`docs/phase2/test_result.txt`).
- 새 시험: 처치·도움, 도움 시간 만료, 상태 효과로 인한 처치의 공 인정, 승패 판정 한 번만, 아군 겹침 방지, 리더 따라가기, 아군 지원, 집중 공격 대상, 우물 피해와 AI 의 우물 회피, 플레이어 근처 대기.
- 3대3 시뮬레이션(240초, 보통·어려움): 여섯 영웅 모두 Q/W/E/R 를 썼고, 최대 끼임 시간 0.52초, 킬 점수 합 = 사망 수, 도움과 따라가기가 실제로 일어남.
- 목표 킬 3 시험: 목표에 이른 팀이 이기고, 결과 창이 뜨고, 그 뒤 점수가 바뀌지 않음.
- 화면 캡처: `docs/phase2/` 의 20:9, 16:9, 4:3.

## 알려진 문제와 남은 작업

- 3대3 에서는 240초에 40킬 안팎이 나서 15킬 경기가 1분 30초쯤에 끝납니다. 아직 레벨이 1에 머물러 부활 시간이 5.5초로 짧기 때문입니다. PHASE 3 에서 레벨업과 부활 시간 증가, 몬스터 사냥이 들어오면 다시 맞춥니다.
- 같은 영웅이 여러 명 나오는 것은 영웅이 2명뿐이라서입니다. PHASE 5 에서 10명이 되면 중복을 막는 선택지를 둡니다.
