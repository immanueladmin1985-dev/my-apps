# PHASE 18 보고서: 목표 킬 직접 정하기, 닌자 방향, 둥근 기둥, 그림자 (1.13.0)

## 목표 킬을 직접 정하기

- 새 게임 화면과 설정 화면의 목표 킬을 10·15·20·30 네 개 중 고르던 방식에서 **[−] 숫자 [+]** 로 바꿨습니다. 1부터 100까지 1씩 정할 수 있고, 바로 저장됩니다(`UiKit.kill_stepper`).
- 1대1 연습은 목표 킬을 10 이하로 줄이던 규칙을 없앴습니다. 정한 숫자 그대로 씁니다.

## 닌자 그림 방향

- 닌자 원래 그림이 오른쪽을 보고 있었는데, 정리 도구가 왼쪽을 보는 그림 목록(`FACING_LEFT`)에 넣어 한 번 더 뒤집고 있었습니다. 그래서 움직이는 방향과 반대로 보였습니다.
- 그림(`ninja.png`, `ninja_face.png`)을 바로잡고 목록에서 뺐습니다.

## 둥근 기둥

- 맵 가운데의 바위 18개를 네모에서 **둥근 기둥**으로 바꿨습니다(`MapData.pillars`: 중심과 반지름). 자리와 크기는 예전과 비슷합니다.
- 충돌은 원형, 길찾기는 16각형으로 피합니다. 시야와 투사체도 막습니다.
- 기울어진 시점에서는 위로 올린 윗면과, 가운데가 밝고 아래로 갈수록 어두운 옆면을 그려 원기둥처럼 보입니다. 벽과 함께 아래쪽(앞쪽)에 있는 것부터 나중에 그립니다.
- 벽(긴 네모)은 그대로입니다.

## 캐릭터의 2.5D 느낌

- 2.5D 시점에서 캐릭터는 바닥과 함께 눕히지 않고 **서 있는 그대로** 그립니다(그림 자체가 비스듬히 내려다본 모습이라 눕히면 납작해 보입니다). 대신 바닥, 범위 표시, 그림자가 타원으로 눕습니다.
- 발밑 그림자를 가장자리가 흐린 타원으로 바꾸고, 기둥 그림자처럼 오른쪽 아래로 살짝 비켜 그려 바닥에 서 있는 느낌을 더했습니다.

## 점검

- 새 시험: 목표 킬 [−]/[+] (1 아래로 안 내려감), 둥근 기둥이 이동과 시야를 막음.
- 자동 시험 173개 모두 통과, 전체 흐름 시험 성공.

## 목표 킬 무제한 (1.14.0)

- 목표 킬을 1 에서 [−] 를 한 번 더 누르면 **무제한**(0)이 됩니다. 이때는 킬 수로 끝나지 않고 최종 보스(고대 흑룡)를 잡아야 끝납니다.

## 영구 비약 (1.14.0)

비싼 값으로 능력치를 영구히 올리는 물약입니다. 아이템을 다 갖춘 뒤 남는 골드를 쓸 곳이 생겨, 늦은 시간에 최종 보스를 잡을 힘을 모을 수 있습니다.

| 비약 | 효과 (한 번 마실 때) |
|---|---|
| 힘의 비약 | 공격력 +10 |
| 마력의 비약 | 주문력 +15 |
| 생명의 비약 | 최대 체력 +150, 체력 회복 +1.5 |
| 강철의 비약 | 방어력 +8, 마법 저항력 +8 |
| 신속의 비약 | 공격 속도 +6%, 이동 속도 +8 |

- 상점 "물약" 칸에 있습니다. 처음 1500 골드이고, 같은 비약을 마실 때마다 250 골드씩 오릅니다. 사면 그 자리에서 마시고 아이템 칸을 차지하지 않습니다. 죽어도 남습니다.
- AI 도 추천 아이템을 다 갖추면 남는 골드로 비약을 마십니다(공격형은 힘, 마법형은 마력, 사이사이 생명·강철).
- 이어 하기 저장에 마신 비약도 들어갑니다.
- 만드는 도구: `tools/gen_elixirs.py`. 아이콘 요청 프롬프트: `docs/ART_PROMPTS.md` 9번 (그림이 없는 동안은 색과 글자로 나옴).
- 새 시험: 영구 비약(값이 오르고, 칸을 안 차지하고, 죽어도 남음), 목표 킬 무제한. 자동 시험 175개 모두 통과, 전체 흐름 시험 성공.

## 영웅 그림 방향 다시 점검, 비약 아이콘 (1.14.1)

- 영웅 16명 그림을 한 장에 크게 모아 하나씩 확인했습니다. 게임은 오른쪽을 보는 그림을 기준으로 왼쪽으로 갈 때 뒤집습니다.
- 메카닉·빙결술사·성녀·총잡이는 원래 오른쪽을 보는 그림인데 왼쪽을 본다고 잘못 판단해 뒤집어 넣었고, 사신·마법소녀는 원래 왼쪽을 보는 그림인데 그대로 넣었습니다. 여섯 명의 그림과 얼굴을 바로잡았습니다.
- 정리 도구의 왼쪽 그림 목록(`FACING_LEFT`)을 사신·마법소녀로 고쳤습니다 (다음에 같은 그림을 다시 넣어도 맞게 들어감).
- 영구 비약 5종 아이콘을 넣었습니다.

## 그림 방향 다시 바로잡기, 좌우 바꾸기 버튼, 공격 버튼, 소모품 버튼 (1.15.0)

- 1.14.1 에서 빙결술사·성녀·사신·마법소녀를 또 반대로 넣었습니다. 사용자 확인대로 네 명을 다시 뒤집었고, 정리 도구의 왼쪽 그림 목록은 성녀·빙결술사(원래 왼쪽을 보는 그림)로 고쳤습니다.
- 그림 방향을 눈으로 판단하다 여러 번 틀렸기 때문에, **영웅 도감에 "그림 좌우 바꾸기" 버튼**을 넣었습니다. 누르면 그 영웅 그림이 전투·도감·새 게임 화면에서 모두 좌우로 바뀌고, 설정에 저장됩니다(`art_flip`).
- **공격 버튼을 영웅마다 다르게** 그립니다(`scripts/ui/attack_icon.gd`, 그림 파일 없이 코드로 그림). 바탕은 영웅 색입니다.
  - 총잡이: 리볼버 탄창. 쏠 때마다 탄창이 한 칸 돌고 총알이 하나씩 빕니다. 마지막 탄은 주황색, 재장전 중에는 탄창이 빙글빙글 돌며 "장전"이 나옵니다.
  - 검성 검, 암살자 쌍단검, 닌자 도는 수리검, 용기사 창, 사신 낫, 엘프 활, 화염술사·빙결술사·성녀 지팡이(불·얼음·빛 구슬), 마법소녀 별 지팡이, 무투가 주먹, 기공사 빛나는 주먹, 성기사 방패와 철퇴, 소환술사 마도서, 기계공 렌치.
  - 고유 게이지가 있으면 버튼 둘레에 보입니다: 검기·연계는 점, 기·분노는 차오르는 고리(가득 차면 반짝임), 영혼은 고리와 숫자.
- **소모품 빠른 사용 버튼**을 Q 버튼 왼쪽 아래에 넣었습니다. 가진 소모품 중 하나를 크게 보여 주고(다쳤으면 체력 물약 먼저, 마나가 적으면 마나 물약), 누르면 바로 씁니다. 개수가 숫자로 나옵니다.
- 자동 시험 176개 모두 통과, 전체 흐름 시험 성공.
