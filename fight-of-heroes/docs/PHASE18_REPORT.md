# PHASE 18 보고서: 목표 킬 직접 정하기, 닌자 방향, 둥근 기둥, 그림자 (1.13.0)

## 목표 킬을 직접 정하기

- 새 게임 화면과 설정 화면의 목표 킬을 10·15·20·30 네 개 중 고르던 방식에서 **[−] 숫자 [+]** 로 바꿨습니다. 1부터 100까지 1씩 정할 수 있고, 바로 저장됩니다(`UiKit.kill_stepper`).
- 1대1 연습은 목표 킬을 10 이하로 줄이던 규칙을 없앴습니다. 정한 숫자 그대로 씁니다.

## 닌자 그림 방향

- 닌자 원래 그림이 오른쪽을 보고 있었는데, 정리 도구가 왼쪽을 보는 그림 목록(`FACING_LEFT`)에 넣어 한 번 더 뒤집고 있었습니다. 그래서 움직이는 방향과 반대로 보였습니다.
- 그림(`ninja.png`, `ninja_face.png`)을 바로잡고 목록에서 뺐습니다.

## 둥근 기둥

- 맵 가운데의 바위 18개를 네모에서 **둥근 기둥**으로 바꿨습니다(`MapData.pillars`: 중심과 반지름). 자리와 크기는 예전과 비슷합니다.
- 충돌은 원형, 길찾기는 16각형으로 피합니다. 시야와 투사체도 막습니다.
- 기울어진 시점에서는 위로 올린 윗면과, 가운데가 밝고 아래로 갈수록 어두운 옆면을 그려 원기둥처럼 보입니다. 벽과 함께 아래쪽(앞쪽)에 있는 것부터 나중에 그립니다.
- 벽(긴 네모)은 그대로입니다.

## 캐릭터의 2.5D 느낌

- 2.5D 시점에서 캐릭터는 바닥과 함께 눕히지 않고 **서 있는 그대로** 그립니다(그림 자체가 비스듬히 내려다본 모습이라 눕히면 납작해 보입니다). 대신 바닥, 범위 표시, 그림자가 타원으로 눕습니다.
- 발밑 그림자를 가장자리가 흐린 타원으로 바꾸고, 기둥 그림자처럼 오른쪽 아래로 살짝 비켜 그려 바닥에 서 있는 느낌을 더했습니다.

## 점검

- 새 시험: 목표 킬 [−]/[+] (1 아래로 안 내려감), 둥근 기둥이 이동과 시야를 막음.
- 자동 시험 173개 모두 통과, 전체 흐름 시험 성공.
