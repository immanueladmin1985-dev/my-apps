# PHASE 4 완료 보고 (아이템과 상점)

## 함께 고친 것 (사용자 의견)

- **궁수 기본 공격이 끝까지 따라옴:** 원거리 기본 공격은 대상을 따라가는 방식을 유지하되(걸어서는 피할 수 없음), 대상이 돌진·도약(검성 Q·R, 궁수 E)을 하면 투사체가 대상을 놓치고 마지막 위치로 날아가 사라집니다.
- **벽 너머 공격(용암 거인 방):** 기본 공격은 벽에 시야가 가리면 사거리 밖으로 보고 벽을 돌아서 다가갑니다. 모든 투사체는 벽에 닿으면 사라집니다.

## 구현한 기능

| 구분 | 내용 |
|---|---|
| 아이템 39종 | 재료 11, 중간 단계 13, 완성품 10, 물약·특수 5. 분류: 무기, 방어구, 신발, 반지, 목걸이, 물약, 특수 |
| 새 능력치 | 쿨타임 감소(최대 40%, 스킬 쿨타임과 버튼 표시에 반영), 흡혈(기본 공격 피해의 비율만큼 회복) |
| 조합 | 재료를 가지고 있으면 "전체 가격 − 가진 재료 가격"만 냄. 재료의 재료까지 계산. 재료는 사라지고 완성품이 한 칸 |
| 상점 규칙 | 기지(우물) 안이나 사망 중에만 구매·판매. 판매는 가격의 70%. 칸 6개. 신발은 하나만(신발 업그레이드는 가능), 완성품은 종류별 1개 |
| 사용 아이템 | 체력 물약(10초 200 회복, 5개까지 쌓임), 마나 물약, 분노의 비약(3분 강화), 강철의 비약, 귀환 두루마리(3초 뒤 기지로, 움직이거나 맞으면 취소) |
| 시작 골드 | 500 |
| 상점 화면 | 추천(영웅별 아이템 순서)·무기·방어구·신발·장신구·물약·특수 분류, 실제 가격(조합 할인)·살 수 없는 이유, 재료와 상위 아이템, 내 아이템 6칸에서 판매, 내 능력치 요약. 기지 밖에서도 목록은 볼 수 있음 |
| 전투 화면 | 체력 막대 위 아이템 6칸(사용 아이템을 누르면 바로 사용, 빈칸을 누르면 상점), 오른쪽 위 "상점" 버튼, 귀환 남은 시간 |
| 터치 | 일시정지·모여·상점·아이템 칸을 손가락 번호와 상관없이 눌리는 버튼으로 바꿈. 조이스틱으로 이동하면서도 누를 수 있음 |
| AI | 영웅별 아이템 순서(HeroData.ai_build)대로 재료부터 삼. 골드 1100 이상 모이면 싸움이 없을 때 기지로 쇼핑하러 감(BUY_ITEM). 9레벨 전까지 체력 물약 2개, 체력 45% 아래에서 마심. 칸이 모자라면 물약을 팔아 자리를 만듦 |
| 데이터 검사 | 재료가 있는지, 가격이 재료 합보다 큰지, 능력치 이름, 사용 아이템 설정, AI 아이템 순서 (CI 의 내보낸 패키지 점검에도 포함) |

컴퓨터에서는 B(상점), 1~6(아이템 칸) 키도 쓸 수 있습니다.

## 테스트 결과

- 자동 시험 93개 모두 통과, 스크립트 오류 0개 (`docs/phase4/test_result.txt`).
- 새 시험: 벽이 기본 공격·투사체를 막음, 돌진하면 기본 공격을 피함, 아이템 데이터, 구매와 능력치 반영, 기지에서만 구매(사망 중 가능), 골드 부족, 조합 비용과 재료 소모, 재료의 재료까지 조합, 칸이 가득 찼을 때, 판매 70%와 능력치 제거, 신발 하나만, 물약 쌓기와 회복, 쿨타임 감소(최대 40%), 흡혈, 귀환(피해 시 취소), **아이템을 갖추면 10초 동안 준 피해가 1.8배 이상**, AI 구매 순서, 이동 중 HUD 버튼·물약 사용, 상점 열고 닫기.
- 경기 전체 시뮬레이션: AI 가 아이템을 사서 장비를 갖춤(영웅마다 장비 2~5개), 15킬 경기 약 6~8분.
