# PHASE 22 보고서: 점검과 손보기, 와이파이 대전 게임 방식 (1.19.1)

## 점검한 것
- 휴대폰(1600x720, 20:9)과 태블릿(1024x768, 4:3) 크기로 처음 화면, 새 게임, 도전과 업적, 전투, 보스 레이드, 와이파이 로비를 캡처해 살펴봤습니다. 겹치거나 잘리는 곳은 없었습니다.
- AI 끼리 경기를 돌려 중반 전투 화면을 확인했습니다.
- 합친 뒤 처음으로 와이파이 대전(밴 단계 + 빠른 대화)을 게임 두 개로 끝까지 돌렸습니다. 스크립트 오류 없이 두 쪽 모두 결과 화면까지 갔습니다.

## 고친 것
- **와이파이 대전 결과 기록**: 참가자 폰에서는 트리플 킬·보스 처치·와드·준 피해가 0으로 남아 업적과 도전 과제에 잡히지 않았습니다. 이제 경기가 끝날 때 방장이 영웅마다 기록을 함께 보내, 참가자 폰의 결과 화면·업적·도전 과제도 방장과 같은 기록을 씁니다.
- **숙련도 메달**: 한 번도 하지 않은 영웅에도 "1" 메달이 붙어 영웅 목록이 어지러웠습니다. 숙련도 점수가 있는 영웅에만 메달을 보입니다(도감, 새 게임).
- **대화 창과 처치 알림**: 대화 창이 열려 있으면 처치 알림을 왼쪽으로 비켜 그려 가리지 않습니다.
- 시험 하나가 남긴 설정이 다른 시험에 영향을 주던 것을 막았습니다.

## 새로 넣은 것: 와이파이 대전 게임 방식
- 방장이 로비에서 **일반 / 짧은 판 / 보스 레이드** 를 고릅니다. 참가자는 고른 방식과 설명을 봅니다.
- **보스 레이드 협동**: 사람은 모두 블루 팀(최대 3명, 빈자리는 AI)이 되어 함께 고대 흑룡을 10분 안에 잡습니다. 레드 자리는 닫히고, 레드에 있던 사람은 블루 빈자리로(없으면 관전으로) 옮겨집니다. 밴 단계는 하지 않습니다.
  - 보스의 위험 지역 예고도 보스가 스킬 장치로 쓰기 때문에 참가자 화면에 그대로 보입니다.
- **짧은 판**: 혼자 할 때와 같이 6레벨·2500골드로 시작하고 5킬을 먼저 올리면 이깁니다.
- 로비 위쪽 줄은 게임 방식에 맞춰 바뀝니다(레이드: "AI 아군 보통", 밴 없음, 빈자리 수 3 기준).
- 개발용 인자 `--lan_game=raid|quick`.

## 점검
- 새 시험 5개(`tests/unit/test_phase22.gd`): 레이드에서 레드 사람 옮기기·레드 자리 막기·시작 설정, 블루가 차 있으면 관전으로, 짧은 판 규칙, 참가자 결과 기록 받기, 로비 게임 방식 줄.
- 실제로 게임 두 개를 띄워 와이파이 보스 레이드를 끝까지 진행했습니다(두 쪽 모두 결과 화면, 스크립트 오류 없음).
- 자동 시험 229개 모두 통과, 전체 흐름 시험 성공.
