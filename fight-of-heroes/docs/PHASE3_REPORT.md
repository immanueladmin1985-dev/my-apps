# PHASE 3 완료 보고 (성장 시스템)

## 구현한 기능

| 구분 | 내용 |
|---|---|
| 경험치·레벨 | 최대 15레벨, 다음 레벨까지 `100 + 60 × (레벨 − 1)`. 레벨업하면 능력치 성장, 늘어난 최대 체력·마나만큼 회복, 스킬 포인트 +1 |
| 스킬 강화 | 1레벨부터 스킬을 직접 배움. Q/W/E 최대 4단계(레벨에 따른 한도), R 은 6·11·15레벨에 한 단계씩. 15레벨에서 포인트 15개를 모두 쓰면 전부 최대 단계 |
| 조작 | 스킬 버튼 왼쪽 위의 초록 "+" 를 눌러 스킬을 올림. 버튼 아래 점으로 단계 표시. 컴퓨터에서는 Ctrl + Q/W/E/R |
| AI 강화 | 레벨업하면 R 을 먼저, 그다음 데이터의 우선순위(Q → W → E)대로 자동으로 올림 |
| 골드 | 초당 2골드, 영웅 처치 250 + 20 × 레벨(도움 영웅이 절반을 나눔), 몬스터 처치(마지막 일격), 보스 처치(팀 전원). 플레이어에게 "+G" 표시 |
| 몬스터 | 늑대 캠프 4곳(우두머리 + 2마리), 바위 골렘(정예, 예고 후 내려찍기) 2곳. 공격받으면 같은 캠프가 함께 반격, 구역을 벗어난 대상은 쫓지 않고, 대상이 없으면 돌아가 회복. 모두 처치되면 45초·90초 뒤 다시 등장 |
| 중립 보스 | 숲의 수호정령(위), 용암 거인(아래). 3분에 등장, 처치 4분 뒤 다시 등장. 처치한 팀 전원에게 120초 버프(숲의 축복: 공격력·주문력 +15%, 체력 회복 / 용암의 힘: 방어력·마법 저항 +25, 최대 체력 +10%) |
| 최종 보스 | 고대 흑룡(중앙). 10분에 등장(1분 전 알림), 처치한 팀이 즉시 승리 |
| 보스 패턴 | 내려찍기(주변 원), 표적 폭발(영웅마다 발밑 원), 돌진(직선 예고 후 돌진), 불비(넓은 지역 여러 곳, 분노 후에만). 모든 패턴은 예고 표시가 먼저 나오고 그동안 보스는 멈춤. 체력 50% 아래에서 분노(공격 속도 +30%, 공격력 +20%) |
| AI 행동 | FARM(사냥터로 이동·사냥), BOSS_FIGHT(보스 공략, 도전 중에는 가까이 온 적에게만 대응). 보스 도전 조건: 2명 이상 생존, 평균 체력 50% 이상, 중립 보스 평균 6레벨·최종 보스 8레벨(상대가 1명 이하만 살아 있으면 바로). 보통·어려움 AI 는 위험 지역을 보고 피함 |
| 화면 | 경험치 막대, 골드, 최종 보스까지 남은 시간, 가까운 보스의 이름·체력 막대(분노 표시), 미니맵에 몬스터·보스 |
| 새 스킬 효과 | 범위 효과 여러 개 흩뿌리기·적마다 하나씩, 직선 위험 지역(돌진 포함), 시전 준비 동작(멈춤) |

## 고친 문제

- **가끔 게임이 멈추던 문제:** 처치된 몬스터가 지워진 뒤에도 영웅의 "최근 공격자" 목록에 남아, 그 목록을 읽던 아군 지원 판단에서 멈췄습니다. 1초마다 지워진 항목과 15초 지난 항목을 정리하고, 읽을 때도 유효한지 먼저 확인합니다. 수정 전에는 4번 중 1번꼴로 멈췄고, 수정 후 14번 연속 정상이었습니다. 시험 실행기에 20초 멈춤 감시를 넣어 같은 일이 생기면 바로 실패합니다.
- **보스가 돌진 후 초기화되던 문제:** 돌진으로 구역 밖에 밀려나면 위협을 유지한 채 걸어서 돌아옵니다. 큰 몬스터가 장애물에 1초 넘게 끼면 캠프 자리로 옮깁니다.
- **피할 수 없는 예고:** 내려찍기 범위 200·예고 1.1초(최종 보스 230·1.2초)로 바꿔 보스 중심에서도 예고 안에 빠져나갈 수 있습니다.

## 밸런스 조정

- 부활 시간 `8 + 2.5 × 레벨`초(최대 45초). AI 시야 600/700/800(쉬움/보통/어려움).
- 엘프 궁수 하향(체력 520, 공격력 52, 공격 속도 0.85, 사거리 400, 관통 화살 피해 감소), 검성 상향(체력 680, 방어력 32). 조정 전에는 궁수 2명인 팀이 25:1, 19:4 로 이겼고 조정 후 3대3 시험은 8:11, 12:6.

## 테스트 결과

- 자동 시험 71개 모두 통과, 스크립트 오류 0개 (`docs/phase3/test_result.txt`).
- 새 시험: 경험치 곡선과 스킬 한도, 레벨업 능력치·회복, 스킬 습득 규칙, 15레벨 포인트 분배, AI 자동 습득(6레벨에 R), 시간당 골드, 영웅 처치 보상, 캠프 동료 반격, 구역 이탈과 회복, 캠프 리스폰과 보상, 보스 내려찍기 예고, 돌진, 분노, 팀 버프와 최종 보스 승리, AI 위험 지역 피하기.
- 보스 공략 시뮬레이션: 10레벨 AI 3명이 최종 보스를 80초(난수 5), 중립 보스를 7레벨에서 52~120초에 처치. 난수 6개로 따로 돌렸을 때 최종 보스는 6번 중 5번(80~190초) 처치.
- 경기 전체 시뮬레이션: 목표 15킬로 끝까지 진행, 보통 약 3.5분, 어려움 약 3.4분. 몬스터 16~49마리 처치, 레벨 3~6.
- 화면 캡처: `docs/phase3/phone.png`(스킬 + 표시·경험치·골드·최종 보스 시간), `docs/phase3/boss.png`(보스 체력 막대·예고).

## 알려진 문제와 남은 작업

- AI 끼리의 15킬 경기는 3~4분이면 끝나고, 앞서 나간 팀이 계속 이기는 경향(눈덩이)이 있습니다. 실제로 플레이어가 하는 경기는 더 길 수 있어 기기에서 확인한 뒤 목표 킬 기본값이나 처치 보상(뒤진 팀 보너스)을 조정합니다.
- 양 팀이 계속 싸우는 경기에서는 AI 가 보스를 잘 잡지 않습니다(보스 처치는 보스 공략 시험에서 따로 확인).
- 골드는 모이기만 하고 쓸 곳이 없습니다. PHASE 4 에서 상점과 아이템을 만듭니다.
