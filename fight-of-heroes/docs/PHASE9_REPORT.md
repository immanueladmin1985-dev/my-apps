# PHASE 9 보고서: 화면 다듬기, 480판 밸런스

## 화면

- **메인 메뉴**: 왼쪽 빈자리에 영웅 다섯 명의 그림을 세웁니다. 가운데는 최근에 고른 영웅이고 가장 크게 그립니다. 태블릿처럼 세로가 긴 화면에서는 가로 폭에 맞춰 줄여 메뉴 버튼을 가리지 않습니다.
- **새 게임**: 남는 자리에 고른 영웅의 전신 그림, 설명, Q·W·E·R 스킬 설명을 보여 줍니다. 그림 크기는 남는 높이에 맞춥니다.
- **영웅 도감**: 오른쪽에 고른 영웅의 전신 그림을 크게 보여 줍니다.
- **그림이 없을 때의 맵 모양**(벽·기지·상점 그림을 받기 전까지 씀):
  - 벽: 회색 상자 대신 그림자, 어두운 옆면, 밝은 윗면, 돌 조각, 이끼가 있는 바위. 벽마다 정해진 무늬입니다.
  - 기지: 돌 광장, 계단 고리, 가운데 팀 색 수정.
  - 상점: 줄무늬 천막과 상자. 기지 위쪽에 놓아 어디서 사는지 보이게 했습니다.
- 휴대폰(2400×1080)과 태블릿(2048×1536)에서 메인 메뉴, 새 게임, 영웅 도감, 전투, 상점 화면을 캡처해 확인했습니다 (`docs/phase9/`).

## 밸런스 (480판씩, 영웅마다 약 280판)

판 수를 4배로 늘려 영웅마다 오차가 약 ±3% 가 되었습니다.

| 영웅 | 조정 전 | 조정 후 |
|---|---|---|
| 무투가 | 62% | 50% |
| 암살자 | 57% | 56% |
| 화염술사 | 55% | 50% |
| 빙결술사 | 54% | 52% |
| 용기사 | 53% | 59% |
| 소환술사 | 49% | 49% |
| 검성 | 46% | 51% |
| 성기사 | 43% | 45% |
| 엘프 궁수 | 42% | 44% |
| 성녀 | 40% | 44% |

- 조정: 무투가 공격력 57→54, 최대 체력 660→640. 엘프 궁수 공격 속도 0.8→0.85, 최대 체력 520→540. 성녀 패시브 치유 45~105→55~130. 성기사 공격력 63→65, 최대 체력 730→760.
- 범위가 40~62% 에서 44~59% 로 줄었습니다. 용기사는 바꾸지 않았는데 53% 에서 59% 로 올랐습니다(상대하는 영웅들이 바뀐 영향). 다음 조정 후보입니다.
- 일방적인 경기(진 팀 3킬 이하)는 480판 중 147·150판(약 31%)입니다.
- 측정 결과: `docs/phase9/balance_before.txt`, `balance_after.txt`. 스크립트 오류 0개.
