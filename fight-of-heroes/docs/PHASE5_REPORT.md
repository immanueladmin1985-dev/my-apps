# PHASE 5 완료 보고 (영웅 10명)

## 함께 고친 것 (사용자 의견)

- **궁수 기본 공격이 너무 멀리까지 따라옴:** 따라가는 투사체의 비행 한도가 3000 이라, 사거리 밖으로 달아나도 끝까지 쫓아갔습니다. 이제 쏜 자리에서 "사거리 × 1.35 + 60"(궁수는 약 600)보다 멀리 달아난 대상은 따라가지 않고 떨어집니다. 변신한 용기사처럼 사거리가 늘어난 경우에도 같은 규칙입니다.

## 새로 만든 장치

| 장치 | 내용 |
|---|---|
| 패시브 (PassiveData, PassiveRunner) | 발동 시점: 기본 공격 적중(n번째마다), 스킬 사용, 일정 시간마다, 처치, 항상. 조건: 대상 체력·자기 체력. 수치는 영웅 레벨에 따라 1·5·9·13레벨에 강해짐 |
| 순간이동 (TeleportEffect) | 지점·방향·대상 뒤로. 순간이동하면 따라오던 기본 공격을 피함 |
| 소환 (SummonEffect) | 주인을 따라다니며 주인이 공격하는 적이나 주변 적을 공격, 시간이 지나거나 주인이 죽으면 사라짐. 소환수의 처치·도움은 주인에게. 주문력·단계에 따라 강해짐 |
| 은신 (STEALTH 상태) | 적이 대상으로 고를 수 없음(범위 공격에는 맞음). 공격·스킬 사용 시 풀림. 아군에게는 반투명, 적에게는 보이지 않음 |
| 변신 | 상태 효과에 그림 크기·색 섞기, 새 능력치 "사거리". 사거리가 크게 늘면 기본 공격이 투사체로 바뀜 |
| 아군 지원 스킬 | 아군 대상 치유·보호막. 자동 조준은 체력 비율이 가장 낮은 아군(자신 포함). AI 는 체력 70% 아래 아군에게 사용(SUPPORT), 소환은 적이 가까울 때(SUMMON) |
| 마나 회복 효과, 지속 피해 3종(화상·중독·저주), 빙결 | |

| 팀 구성 | 영웅이 충분하면 6명 모두 다른 영웅 |

## 알려진 문제

- 앞서 나간 팀이 계속 이기는 경향(눈덩이)이 있어 15킬 경기가 5분 안쪽으로 끝나는 경우가 있습니다. PHASE 6 에서 뒤진 팀 보상(현상금 등)과 영웅별 밸런스를 맞춥니다.
