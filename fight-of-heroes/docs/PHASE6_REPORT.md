# PHASE 6 완료 보고 (완성과 최적화)

## 화면 흐름

게임 실행 → **메인 메뉴** → **새 게임**(게임 모드·영웅·팀 구성) → 전투 → **결과** → 다시 하기 / 영웅 바꾸기 / 메인 메뉴.
각 화면은 독립된 Scene 입니다 (`scenes/menu`, `scenes/selection`, `scenes/results`).

| 화면 | 내용 |
|---|---|
| 메인 메뉴 | 새 게임, 영웅 도감, 아이템 도감, 게임 기록, 설정, 게임 종료(확인 창). 전적 요약·최근 영웅·버전 |
| 새 게임 | 게임 모드(3대3 대전 / 1대1 연습 / AI끼리 관전), 영웅 10명 카드, 팀 구성(무작위 / 직접 구성: 칸을 누르고 영웅을 누름, 빈칸은 겹치지 않는 무작위), AI 난이도, 목표 킬 |
| 영웅 도감 | 능력치(기본·레벨당 증가), 패시브, 스킬별 최대 단계·마나·쿨타임·사거리, 추천 아이템, 내 기록 |
| 아이템 도감 | 분류별 목록, 능력치·가격·재료·조합 비용·상위 아이템·판매 가격 |
| 게임 기록 | 전적·승률·최고 킬, 영웅별 경기·승률·평균 킬/데스/도움, 최근 경기 30개, 기록 초기화(확인 창) |
| 설정 | AI 난이도, 목표 킬, 효과음 크기, 피해 숫자 표시, FPS 표시, 배터리 절약(30fps). 바로 저장 |
| 결과 | 승리/패배, 사유, 점수, 경기 시간, 양 팀 영웅별 레벨·킬/데스/도움·골드·영웅에게 준 피해·아이템, MVP |

- 공통 테마(둥근 버튼, 한글 글꼴)와 화면 도구(`scripts/ui/ui_kit.gd`). 확인 창은 화면 안의 창으로 만들었습니다.
- 안드로이드 **뒤로 가기** 버튼(컴퓨터에서는 ESC): 메뉴 화면은 이전 화면으로, 메인 메뉴는 종료 확인, 전투는 일시정지·상점 닫기.
- 전투 중 다른 앱으로 가거나 화면이 꺼지면 자동으로 일시정지하고 저장합니다.

## 저장

- `user://save.json`(JSON). 버전 2: 설정, 전적(경기·승·패·최고 킬), 영웅별 기록, 최근 경기 30개. 버전 1 파일은 자동으로 옮깁니다.
- 관전 모드 경기는 기록하지 않습니다.
- **전투 도중 앱 종료 대비(설계):** 지금은 앱이 멈추면 설정·기록을 저장하고 전투를 일시정지합니다. 전투 상태를 통째로 이어 하려면 다음을 저장하면 됩니다: 경기 설정(MatchConfig), 경기 시간·킬 점수·연속 처치, 영웅별(위치·체력·마나·레벨·경험치·골드·스킬 단계·쿨타임·아이템 칸·상태 효과·부활 남은 시간), 캠프별(남은 리스폰 시간·살아 있는 몬스터 체력), 보스 단계, 팀 계획. 모두 JSON 으로 표현할 수 있는 값이라 `SaveManager` 에 `battle_snapshot` 항목을 두고, 앱 일시정지 신호에서 저장 → 다음 실행 때 "이어 하기"로 복원하는 순서입니다. 투사체·위험 지역처럼 몇 초 안에 끝나는 것은 저장하지 않습니다.

## 사운드·이펙트

- 효과음 11가지(타격, 치명타, 피격, 스킬, 처치, 레벨업, 구매, 보스, 승리, 패배, 버튼)를 시작할 때 코드로 합성합니다(`scripts/core/audio_manager.gd`). 소리 파일이 생기면 같은 이름으로 바꿔 넣으면 됩니다. 플레이어와 관련된 사건과 영웅 처치·보스 알림에만 소리를 냅니다.
- 이펙트: 기본 공격 타격 불꽃(치명타는 더 크게), 레벨업 금색 고리와 "레벨 업!", 처치 시 퍼지는 고리.

## 밸런스

- **현상금:** 연속 처치 중인 영웅을 잡으면 (연속 처치 − 1) × 60 골드(최대 300)를 더 받습니다.
- **따라잡기 경험치:** 평균 레벨이 낮은 팀이 영웅을 잡으면 레벨 차이 1마다 경험치 15%(최대 60%)를 더 받습니다.
- **밸런스 측정 도구:** `tools/run_tests.sh --balance --games=40` 이 무작위 3대3 을 AI 끼리 돌려 영웅별 승률을 냅니다.
- 측정 결과에 따라 성녀·빙결술사·화염술사·성기사를 올리고 암살자·엘프 궁수·무투가를 내렸습니다. 지원 AI 는 아군 체력 85% 아래부터 치유합니다.

| 측정 | 가장 낮은 승률 | 가장 높은 승률 |
|---|---|---|
| 조정 전 (30판) | 성녀 8% | 암살자 72% |
| 1차 조정 (30판) | 성녀 15% | 무투가 69% |
| 2차 조정 (40판) | 소환술사 39% | 용기사 61% |

| 오류 수정 후 최종 (40판) | 성녀 6% (17판) | 성기사 75% (24판) |

최종 측정 결과는 `docs/phase6/balance_final.txt` 에 있습니다. 영웅 하나가 나온 판이 17~31판뿐이라서 측정할 때마다 순위가 크게 흔들립니다(2차 조정 때 39~61% 였던 값이 AI 오류를 고친 뒤 다시 측정하자 6~75% 로 바뀌었습니다). 다만 성녀는 모든 측정에서 가장 낮은 쪽에 있었기 때문에, 판 수를 늘린 측정과 함께 성녀를 다시 조정하는 일을 남은 일로 둡니다.

마지막 측정 중에 AI 가 이미 사라진 소환수·몬스터를 대상으로 들고 있다가 스크립트 오류(`Left operand of 'is' is a previously freed instance`)를 내는 문제를 찾아 고쳤습니다. 고친 뒤 40판 측정에서 스크립트 오류는 0개였습니다.

## 최적화

- 배터리 절약 설정(30fps). 기본은 60fps 제한.
- 투사체가 쏜 쪽 함수를 직접 붙잡지 않고 쏜 유닛을 확인한 뒤 피해를 주도록 바꿨습니다(쏜 쪽이 사라진 뒤 엉뚱한 객체에서 함수를 부르던 오류 수정).
- 작업 환경(그래픽 카드 없음)에서 영웅 6명과 몬스터 20여 마리 전투를 실제 시간보다 약 15배 빠르게 시뮬레이션합니다.
