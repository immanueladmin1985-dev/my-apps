# PHASE 21 보고서: 밴 단계, 관전 자리, 빠른 대화, 도전 과제·업적·숙련도, 짧은 판·보스 레이드 (1.19.0)

네 갈래로 나눠 동시에 만들고 하나로 합쳤습니다.

## 밴 단계 (`scripts/core/ban_phase.gd`, `scripts/ui/ban_board.gd`)
- 새 게임 화면의 "밴" 버튼으로 켜고 끕니다(기본 켬, 설정 `ban_phase`). 시작을 누르면 밴 화면이 열립니다.
- 블루 → 레드 → 블루 → 레드 순서로 팀마다 2명을 금지합니다. 차례마다 20초이고, 시간이 지나면 대신 금지합니다. 블루는 플레이어가, 레드는 AI(강한 영웅과 플레이어가 자주 쓰는 영웅을 더 자주 금지)가 고릅니다.
- 금지한 영웅은 아무도 고를 수 없습니다(무작위 팀, 직접 구성 빈칸, 다시 하기, 와이파이 대전 AI 빈자리 모두). 이미 고른 영웅이 금지되면 다른 영웅으로 바뀌고, 영웅 고르기 화면으로 돌아갑니다.
- 와이파이 대전: 방장이 로비에서 밴 단계를 켭니다. 모두 같은 밴 화면을 보고, 각 팀의 가장 앞자리 사람이 금지합니다(사람이 없는 팀은 AI). 방장이 요청마다 차례와 담당을 확인합니다. 끝나면 방으로 돌아와, 금지된 영웅을 고른 사람은 자동으로 바뀌고 방장이 다시 시작합니다.

## 관전 자리 (와이파이 대전)
- 6자리가 차면 2명까지 관전으로 들어옵니다. 로비에 "관전 (n/2)" 줄과 "관전으로" 버튼이 있습니다.
- 관전자는 영웅 없이 안개 없이 경기를 보고, 미니맵·얼굴 누르기·끌기로 카메라를 옮깁니다. 관전자가 보내는 조작은 방장이 무시합니다.

## 빠른 대화 (`scripts/core/quick_chat.gd`)
- 오른쪽 위 "신호" 아래 "대화" 버튼. 문장 12개(도와줘!, 후퇴하자, 모여서 싸우자, 보스 잡자, 잘했어!, 고마워 등)와 "우리 팀에게만 / 전체에게" 전환.
- 미니맵 아래에 "[팀] 이름: 문장"이 4줄까지 보이고 6초 뒤 사라집니다. 1.5초에 한 번만 보낼 수 있습니다.
- 와이파이 대전에서는 방장이 번호·간격을 확인한 뒤 같은 팀(또는 전체)에게만 보냅니다.
- AI 아군 반응: 도와줘·모여 → 보낸 곳으로 모임, 후퇴 → 6초 동안 우물로 물러남, 보스 잡자 → 가장 가까운 보스를 공격 신호로 찍음. 잠시 뒤 "알겠어!", "가는 중!"으로 대답합니다. 경기가 끝나면 상대 AI 가 가끔 "좋은 경기였어"라고 합니다.

## 도전 과제·업적·영웅 숙련도 (`scripts/save/progress_meta.gd`, `scenes/menu/challenges.tscn`)
- 영웅 숙련도: 승리 100점, 패배 40점, 처치 1번 10점, 도움 1번 5점. 1~7단계(0/200/500/1000/1800/3000/5000). 도감과 영웅 고르기에서 얼굴 옆 메달로 보이고, 결과 화면에 "숙련도 +n"과 단계 오름이 나옵니다.
- 오늘의 도전 과제: 날짜로 정해지는 3개(쉬움·보통·어려움, 별 1/2/3개). 날짜가 바뀌면 새로 바뀝니다.
- 업적 16개: 첫 승리, 10승·50승, 30판, 트리플 킬, 한 판 10킬, 누적 100킬, 흑룡 사냥꾼, 보스 10마리, 어려움 승리, 무결점 승리, 무제한 승리, 모든 영웅 플레이, 숙련도 7단계, 와이파이 대전, 도전 과제 10개. 달성하면 결과 화면에 알림이 뜹니다.
- 처음 화면에 "도전과 업적" 버튼과 오늘의 과제 진행 줄을 넣었습니다. 관전과 자동 진행 경기는 세지 않습니다. 기록을 지워도 숙련도와 업적은 남습니다.

## 게임 방식: 짧은 판, 보스 레이드 (`MatchConfig.game_type`)
- 새 게임 화면의 "게임 방식"(일반 / 짧은 판 / 보스 레이드).
- 짧은 판: 모두 6레벨·2500골드로 시작(스킬 자동 배움), 목표 5킬, 부활 시간과 몬스터 첫 등장 절반, 최종 보스 5분.
- 보스 레이드: 우리 팀 셋(8레벨·3000골드)이 맵 가운데에 20초 뒤 나타나는 고대 흑룡(체력 2.2배)을 10분 안에 잡습니다. 셋이 한꺼번에 쓰러지거나 시간이 다 되면 실패입니다. 위쪽에 남은 시간, 보스 체력 막대가 늘 보입니다. 레이드 보스는 물러나도 체력이 다시 차지 않습니다. 이어 하기 저장은 하지 않습니다.
- 아군 AI 는 평균 9레벨이 되거나 2분이 지나면(또는 플레이어가 보스를 치면) 보스에 모입니다.
- 난이도: 체력 1.6배에서는 AI 셋이 4분 30초 만에 잡아 너무 쉬워서 2.2배로 올렸습니다. AI 셋만으로 약 7분 25초(10분 중) 걸립니다.

## 아직 부족한 점
- 와이파이 대전에서 참가자 폰은 보스 처치·트리플 킬·와드 기록을 세지 못합니다(방장만 셈). 와이파이 로비에는 게임 방식 선택이 없습니다(늘 일반).
- 관전 자리는 단위 시험으로만 확인했고 실제 기기 8대로는 해 보지 않았습니다.
- 대화 창이 열려 있으면 처치 알림 일부를 가립니다.
