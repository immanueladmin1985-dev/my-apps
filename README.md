## 성경 부루마블 (`bible-marble/`)

주사위를 굴려 성경의 땅을 여행하고 말씀 퀴즈를 푸는 2~4인 보드게임입니다. 설치 없이 브라우저에서 열리고, 한 번 연 뒤에는 인터넷 없이도 열립니다(함께하기 제외).

- 보드 판 세 가지: 신구약(우르에서 바울의 선교까지), 구약(에덴 동산에서 출발), 신약(베들레헴에서 출발). 판의 시대에 맞는 퀴즈와 말씀 카드만 나옵니다.
- 말씀 퀴즈 약 260문항(객관식·주관식). 컴퓨터는 객관식만 풀고, 주관식은 소리 내어 답한 뒤 진행자가 정답·오답을 누릅니다.
- 객관식을 틀리면 나머지 모두(컴퓨터 포함)가 동시에 답하고 맞힌 사람끼리 상금 전부를 나누는 "객관식은 모두 도전", 주관식을 다른 팀이 이어서 풀 수 있는 "다른 팀에게 기회"(상금 절반) 규칙, 객관식·주관식 따로 정하는 퀴즈 제한 시간, 컴퓨터 차례 퀴즈를 직접 넘기기 등 설정을 탭으로 나누어 고를 수 있습니다.
- 사람 플레이어마다 화면 주사위와 실물 주사위(나온 숫자 입력)를 고르고, 컴퓨터는 자동으로 굴립니다. 플레이어 색과 동물 캐릭터도 바꿀 수 있습니다.
- 머리줄의 되돌리기 버튼으로 사람이 한 선택을 하나씩 되돌립니다. 주사위 눈과 문제는 그대로 유지됩니다.
- 휴대폰 세로·가로, 태블릿, PC, TV 크기에 맞춰 보드와 양옆 상황판 크기가 바뀝니다. 설정의 글자 크기로 더 크게 볼 수 있습니다.
- 콘텐츠 관리: 퀴즈·보드 판·말씀 카드를 목록에서 켜고 끄고, 고치고, 추가·삭제할 수 있습니다. 엑셀(.xlsx)·CSV로 내보내고 불러올 수 있고, 잘못된 줄은 몇째 줄인지 알려 줍니다. 전체 백업(.json)도 됩니다.
- 성경 본문: 가지고 있는 개역개정 텍스트 파일을 콘텐츠 관리 → 성경 본문에서 불러오면, 게임 속 📖 구절을 누를 때 본문이 큰 글씨로 나옵니다. 본문은 그 기기 안(IndexedDB)에만 저장되고 이 저장소에는 들어 있지 않습니다.
- 함께하기(여러 기기): 방을 만들 때 진행 방식을 먼저 고릅니다.
  - **플레이어 모드**: 방장도 플레이어 한 명으로 참가합니다. 각자 자기 자리만 조작할 수 있고(방장도 남의 주사위·선택을 대신할 수 없음), 주관식은 각자 입력하면 게임이 채점합니다(띄어쓰기·공백·문장부호 차이는 허용). 공평하게 하려고 되돌리기는 쓰지 않습니다.
  - **중계 모드**: 방장은 진행자·심판입니다. PC에서는 "게임 화면 창"을 따로 띄워 TV(확장 모니터)에 보여 주고, 진행자 창에서 정답을 보며 판정합니다. 태블릿에서는 한 화면에서 진행하고, 정답은 태블릿에 보이지 않습니다(필요하면 진행자 휴대폰을 PIN으로 "진행자 리모컨"으로 연결해 정답 확인·판정). 참가자 휴대폰에는 내 상황판과 다른 플레이어 목록이 나옵니다. 휴대폰이 없는 팀은 "진행자 조작" 자리로 둘 수 있습니다.
  - 자리마다 고유 ID와 열쇠가 있어서, 새로고침·앱 종료·잠깐 끊김 뒤에도 같은 자리로 돌아갑니다. 방장이 나갔다가 "이어하기"를 누르면 같은 방 코드로 방이 다시 열립니다. 방 코드는 게임판 가운데와 설정 → 멀티플레이에서 보고 복사할 수 있습니다.
  - 게임 중 새 사람이 들어오면 방장에게 "컴퓨터 자리를 넘겨줄지" 묻고, 참가자가 나간 채 돌아오지 않으면 "컴퓨터로 대체할지"(난이도 선택) 묻습니다. 자리를 바꿔도 위치·달란트·땅·건물·카드는 그대로 이어집니다.
  - 함께하기를 누르면 방 목록이 나옵니다. 방마다 방 이름, 방장, 진행 방식, 인원(예: 1/4), 공개 여부, 보드 판, 난이도, 라운드, 게임 중인지가 보입니다. 방을 만들 때 방 이름과 공개·비공개를 정하고, 비공개 방은 비밀번호를 자동으로 만들거나 직접 정합니다(비밀번호는 서버에 올리지 않고 방장 기기만 확인).
  - 진행자 리모컨(중계 모드, PIN 필요): 게임판 대신 지금 상황과 정답·해설을 미리 보여 주고, 판정·계속하기, 플레이어 관리(컴퓨터 대체·난이도·진행자 조작), 달란트 직접 조정, 되돌리기, 잠시 멈춤을 할 수 있습니다.
  - 방 공유하기를 누르면 카카오톡·문자 등으로 링크를 보낼 수 있고, 받은 사람은 이름만 적으면 바로 들어옵니다. 다른 브라우저로 다시 들어와도 같은 이름이면 원래 자리로 돌아갑니다.
  - 대기실에서는 정한 인원까지 컴퓨터로 채워 두고, 사람이 들어오면 컴퓨터 한 자리를 넘겨받습니다(최대 4명). 나간 사람이 잠시 돌아오지 않으면 그 자리는 컴퓨터로 채우고, 인원을 줄여도 들어와 있는 사람은 내보내지 않습니다.
  - 연결: `js/firebase-config.js`에 Firebase 설정이 있으면 Firebase Realtime Database를 중계 서버로 씁니다(아이폰·카카오톡 앱 안 브라우저·LTE에서도 안정적). 설정이 비어 있으면 PeerJS로 기기끼리 직접 연결합니다. PC 중계 모드의 게임 화면 창은 같은 PC 안에서 연결되므로 인터넷이 없어도 됩니다.

### Firebase 설정 (함께하기 연결)

1. https://console.firebase.google.com 에서 프로젝트를 만듭니다(애널리틱스 끔).
2. Authentication → 로그인 방법 → **익명**을 켭니다.
3. Realtime Database → 데이터베이스 만들기(싱가포르 asia-southeast1, 잠금 모드) → 규칙 탭에 아래 규칙을 붙여 넣고 게시합니다.
4. 프로젝트 설정 → 내 앱 → 웹 앱 등록 → `firebaseConfig` 값을 `bible-marble/js/firebase-config.js`의 `window.FIREBASE_CONFIG`에 넣습니다. 이 값은 공개되어도 되는 식별자이고, 보안은 아래 규칙이 맡습니다(방장만 방 안의 우편함을 읽고, 각 기기는 자기 우편함만 읽고 씀).

```json
{
  "rules": {
    "lobby": {
      ".read": "auth != null",
      "$code": {
        ".write": "auth != null && (!data.exists() || data.child('hu').val() === auth.uid)",
        ".validate": "!newData.exists() || (newData.child('hu').val() === auth.uid && newData.child('title').isString() && newData.child('title').val().length <= 40)"
      }
    },
    "rooms": {
      "$code": {
        "meta": {
          ".read": "auth != null",
          ".write": "auth != null && (!data.exists() || data.child('host').val() === auth.uid)",
          ".validate": "!newData.exists() || newData.child('host').val() === auth.uid"
        },
        "hp": {
          ".read": "auth != null",
          ".write": "auth != null && root.child('rooms').child($code).child('meta/host').val() === auth.uid"
        },
        "in": {
          ".read": "auth != null && root.child('rooms').child($code).child('meta/host').val() === auth.uid",
          ".write": "auth != null && root.child('rooms').child($code).child('meta/host').val() === auth.uid",
          "$id": {
            ".write": "auth != null && !data.exists() && newData.child('f').val() === auth.uid",
            ".validate": "newData.child('s').isString() && newData.child('s').val().length < 8000"
          }
        },
        "q": {
          "$uid": {
            ".read": "auth != null && auth.uid === $uid",
            ".write": "auth != null && (auth.uid === $uid || root.child('rooms').child($code).child('meta/host').val() === auth.uid)"
          }
        },
        "pr": {
          ".read": "auth != null && root.child('rooms').child($code).child('meta/host').val() === auth.uid",
          ".write": "auth != null && root.child('rooms').child($code).child('meta/host').val() === auth.uid",
          "$uid": {
            ".write": "auth != null && auth.uid === $uid"
          }
        }
      }
    }
  }
}
```
- 게임 중에는 머리줄을 없애고 게임판을 최대한 크게 보여 줍니다. 게임판 가운데의 ↩️(되돌리기, 확인 후 실행)와 ⚙️(설정) 버튼만 남기고, 설정은 게임·멀티플레이·게임 규칙·퀴즈·컴퓨터·화면·소리·콘텐츠로 나뉩니다.
- 주사위 차례가 되면 굴릴 사람의 화면에 큰 버튼만 나오고, 굴린 주사위는 모든 기기에서 화면 전체에 크게 굴러 결과가 또렷하게 보입니다(컴퓨터 주사위 포함). 말씀 카드·이벤트는 사람 차례에는 확인을 눌러야 넘어가고, 컴퓨터 차례에는 남은 시간 막대와 함께 5초 동안 보여 줍니다.
- 산 땅은 주인 색 배경 그대로이고, 건물을 지으면 칸 위에 장막(커튼이 드리운 모양)·집(지붕)·성(뾰족한 성 지붕) 장식과 굵은 테두리가 생깁니다.
- 가진 땅은 상황판에 카드 패처럼 부채꼴로 놓이고, 카드를 누르면 꺼내어 크게 보여 줍니다.
- 통행료·십일조처럼 돈이 오가면 10 단위는 동전, 100 단위는 지폐가 낸 사람에게서 받는 사람에게 날아가고, 낸 쪽에는 빨간 −금액, 받는 쪽에는 초록 +금액이 크게 뜹니다.
- 돈이 모자라면 "어느 땅을 파시겠습니까?"라고 묻고, 고른 땅을 건물과 함께 통째로 반값에 팝니다(건물만 따로 팔지 않음). 다 팔아도 모자라면 파산합니다.
- 라운드 수는 10·20·30 가운데 고르거나 직접 숫자를 넣을 수 있고, "파산까지"를 고르면 한 명만 남을 때까지 계속합니다.
- 불수레(원하는 칸으로) 칸에서는 게임판을 보며 날아갈 칸을 고릅니다.
- 캐릭터에 기기에 있는 사진을 넣을 수 있습니다. 동그란 점선 안만 선명하게 보이고, 두 손가락으로 확대·축소·회전해서 맞춥니다. 사진은 작게 줄여 기기 안에만 저장하고, 함께하기에서는 같은 방 기기들에게만 전달합니다.
- 소리 설정에서 잔잔한 1분짜리 배경 음악(끊김 없이 반복)을 켜고 끄고 크기를 고를 수 있습니다. 참가자 휴대폰에서는 처음에 꺼져 있습니다.
- 설정 → ✨ 추가 기능에서 아래 기능을 하나씩 켜고 끕니다.
  - 🃏 성경 인물 카드 수집: 퀴즈·암송 미션을 맞히거나 헌금함 칸에 가면 인물 카드를 받습니다. 인물마다 한 번 쓰는 능력(다윗 통행료 면제, 모세 광야 탈출, 에스더 원하는 칸 이동, 요셉 200 받기, 엘리야 헌금함 절반, 룻 모두에게서 30씩)이 있고, 여섯 명을 모으면 500 달란트를 받습니다.
  - 🤝 플레이어끼리 땅 거래: 주사위를 굴리기 전에 땅과 달란트를 바꾸자고 제안하고, 상대가 받아들이면 바로 바뀝니다. 컴퓨터는 받는 쪽이 넉넉히 이득일 때만 받아들입니다.
  - 📜 말씀 암송 미션 칸: 퀴즈 칸 하나가 암송 미션 칸이 되어 구절의 빈칸 채우기 문제가 나옵니다. 사용자가 불러온 성경 본문이나 직접 넣은 구절만 쓰고, 저장소에는 구절 주소만 있습니다.
  - ⏱ 시간 제한: 정한 시간이 지나면 그 라운드까지만 하고 끝냅니다. 진행자가 멈춘 동안은 시간이 가지 않습니다.
  - 👥 팀전: 함께하기에서 한 자리에 여러 기기가 팀원으로 들어와, 팀원 휴대폰 어느 것으로든 그 팀 차례를 조작합니다.
  - 🎤 진행자 즉석 문제: 진행자(중계 모드의 리모컨·진행자 화면, 한 기기 게임의 설정)가 입력한 문제를 다음 차례 사람이나 모두에게 냅니다.
  - 🏆 게임 기록·명예의 전당, 🎉 승리 연출(폭죽·시상대)과 결과 이미지 저장·보내기.
- 플레이어 말은 칸 안쪽 가장자리에 놓여 땅 이름과 통행료를 가리지 않고, 같은 칸에 여럿이 있으면 나란히 놓입니다.
- 홈 화면 설치, 전체화면, 화면 꺼짐 방지, 자동 저장과 이어하기를 지원합니다.

파일 구성: `index.html`(화면 틀), `css/game.css`, `js/`(엔진·AI·화면·통신), `js/data/`(기본 보드·퀴즈·카드), `vendor/peerjs.min.js`(MIT), `vendor/firebase-*-compat.js`(Apache-2.0, 함께하기를 쓸 때만 불러옴), `sw.js`(오프라인).

## 난장이의 피아노 교실 (`piano/`)

피아노를 처음 치는 사람이 코드(화음)를 차근차근 익히는 연습 앱입니다. 팬플룻 교실과 같은 모양의 PWA로, `piano/` 폴더를 그대로 웹에 올리면 홈 화면에 설치할 수 있습니다.

- 다섯 단계: 첫걸음(건반·손가락·반음) → 기본 코드(C, Cm) → 7화음 → 색깔 코드(sus·dim·aug) → 활용(자리바꿈, 코드 진행, 노래 반주)
- 코드 이름은 정석 표기로 보여 줍니다. 예: Cm = 도 · 미♭ · 솔 (미♭이 레♯과 같은 건반이라는 안내를 함께 표시)
- 입력 방법 세 가지를 함께 쓸 수 있습니다.
  - 화면 건반: ‘콕콕’(하나씩 켜기) / ‘꾹’(누르는 동안) 방식
  - 디지털피아노 MIDI 연결 (안드로이드 크롬, PC 크롬·엣지)
  - 마이크: 진짜 피아노 소리를 듣고 여러 음을 함께 판정 (https 주소나 설치한 앱에서 동작)
- 연습: 코드 원리 배우기, 건반 찾기, 반음·온음 세기, 코드 짚기, 코드 이름 맞히기, 귀로 맞히기, 코드 진행(기다려 줘요 / 박자대로, 가까운 자리바꿈 추천), 노래 반주(작은 별, 환희의 송가, 생일 축하 노래, 징글벨, 어메이징 그레이스)
- 그 밖에: 누른 건반의 코드 이름 알아보기, 코드 사전, 메트로놈, 연습 기록과 코드별 실력, 기록 파일 보관
- 가로 화면 우선 배치: 위쪽은 문제 카드와 단추, 아래쪽은 큰 건반. 보이는 흰 건반 수는 가로·세로 화면마다 따로 정할 수 있습니다 (기본: 가로 약 한 옥타브 반).
- 지연 시간 보정: 듣는 장치(스피커, 블루투스 이어폰 등)마다 화면 터치 지연과 피아노(MIDI·마이크) 지연을 재서 ‘박자대로’ 판정에서 빼 줍니다.
- 처음 열면 홈 화면 설치 방법을 안내합니다 (안드로이드 크롬은 바로 설치, 아이폰·삼성 인터넷은 순서 안내).

## 난장이의 피아노 교실 2 (`piano-v2/`)

만들던 피아노 교실의 다른 판본을 따로 올린 앱입니다. `piano/`보다 앞선 판본을 바탕으로 하며, 설정에서 건반 크기(크게·보통·작게)를 고를 수 있습니다. 박자 지연 보정, 소리 출력 장치 선택처럼 `piano/`에만 있는 기능은 들어 있지 않습니다. 저장 기록은 `piano/`와 따로 보관됩니다.

## 난장이의 팬플룻 교실 (`panflute/`)

마이크로 팬플룻 소리를 듣고 음이 높은지 낮은지 바로 알려 주는 단계별 연습 앱입니다.

- 네 단계: 첫걸음(소리 내기 안내, 관 배치도, 음정 보기, 롱톤) → 기본기(음 맞추기, 음계, 텅잉, 메트로놈) → 넓히기(관 건너뛰기, 곡 따라 불기, 녹음) → 표현하기(비브라토, 반음 꺾기, 레가토, 악상기호, 부점 리듬, 곡 박자대로, 내 곡 만들기, 불어서 악보 만들기, 반주 맞춰 녹음)
- 연습곡: 저작권이 끝난 민요·찬송가·세계 명곡·동요의 가락, 키·빠르기 조절, 내 팬플룻(관 수·조)에 맞춰 옥타브 자동 조정
- 듣는 장치(스피커·블루투스 이어폰)마다 소리 지연을 재서 박자 판정에 반영
- 악보 보기: 기본은 노래방 자막처럼 두 줄씩 보여 주는 방식입니다. ‘따라 불기’처럼 기다려 주는 연습은 부른 음표 색이 바뀌고, ‘박자대로 불기’는 진행바가 줄 위를 지나갑니다. 한 줄을 다 불면 다 분 줄 자리에 다음 줄이 나타나서 보고 있는 줄은 움직이지 않습니다. 설정 → 악보 보기에서 예전의 흐르는 악보(리듬게임 방식)로 바꿀 수 있습니다.
- 연습 화면 공통 틀(1.5): 모든 연습 화면을 위에서 아래로 한 줄로 쌓고(왼쪽·오른쪽으로 나누지 않음) 스크롤 없이 한 화면에 맞춥니다. 위쪽은 지금 음과 ‘지금 할 일’ 안내, 가운데는 큰 화면(악보·바늘·목표 음), 아래는 음정 막대와 소리 정보, 관 한 줄, 버튼입니다. 화면이 모자라면 덜 중요한 칸(소리 정보 → 관 줄)부터 숨깁니다.
- 설정은 머리줄 아래(가로 화면은 제목 옆)의 한 줄 요약을 누르면 아래에서 올라오는 창에서 바꿉니다. 키·빠르기·즐겨찾기·켜고 끄는 항목이 모두 이 창에 있습니다.
- 관 배치도는 관을 모두 한 줄에 넣어 화면 너비에 맞춥니다(옆으로 밀지 않음).
- 가로 화면: 휴대폰 가로에서는 아래 메뉴가 왼쪽 세로 메뉴로 바뀌고, 큰 화면 아래에 관 한 줄과 작은 시작·멈춤 버튼을 둡니다. 음정 보기는 위에 바늘, 아래에 목표 음 관 한 줄입니다. 글자 크기는 화면 크기에 맞춰 자동으로 조절합니다.
- 첫 화면에는 연습 시간·연속 기록을 띄우지 않고, ‘기록’ 탭에서만 보여 줍니다.
- 설정 저장: 같은 앱을 홈 화면 앱과 브라우저 탭 등 두 곳에 열어 두어도, 한쪽에서 바꾼 마이크·감도 설정을 다른 쪽이 옛값으로 덮어쓰지 않습니다. 고른 입력 마이크는 장치 번호가 바뀌어도 이름으로 다시 찾습니다. 설정 → 마이크에서 감도를 직접 조절할 수 있습니다.
- 가로 휴대폰의 악보 화면: 머리줄을 숨기고 악보를 화면 가득 보여 줍니다. 아래에는 소리 정보, 작은 버튼, 재생·정지만 남고, 오른쪽 위 ‘메뉴’를 누르면 아래에서 설정 창(나가기·도움말·전체화면 포함)이 올라오며 악보는 위에 그대로 보입니다.
- 음표 옆 높낮이 표시: 불고 있는 음표 옆에 ‘✓ 맞아요 / ▲ 조금 높아요 / ▼ 조금 낮아요 / 지금 라 · 낮은 관으로’가 떠서 가로·세로 모두 음정을 바로 볼 수 있습니다.
- 박자대로 하는 연습은 시작 전에 정한 빠르기로 3·2·1(한 마디)을 화면 가운데에 크게 세어 줍니다.
- 빠르기: 숫자를 누르면 직접 적을 수 있고, 아래 작은 즐겨찾기 줄에 연습마다 자주 쓰는 빠르기를 저장해 두고 눌러서 불러옵니다.
- 소리 정보 줄: 연습하는 동안 지금 소리의 주파수·센트, 목표 음의 주파수, 음을 고르게 유지한 시간(오늘 최고·전체 최고), 오늘 이 연습을 한 시간을 함께 보여 줍니다.
- 연습 결과는 큰 창 대신 위쪽의 작은 결과 줄로 보여 주고, ‘자세히’를 누르면 전체 결과가 나옵니다.
- 홈: 단계마다 접고 펼 수 있고, 별표를 누른 연습은 맨 위 ‘자주 하는 연습’에 모입니다. 연습곡: 곡 이름 찾기와 별표 즐겨찾기를 지원합니다.
- 설정은 내 팬플룻 · 음정·마이크 · 보기 · 소리·이어폰 · 화면·설치 · 추가 기능 탭으로 나뉩니다. 보기 탭에서 홈 연습 목록 방식(단계별로 접기 / 단계별 탭)과 악보 크기(보통 / 크게 / 아주 크게)를 고릅니다.
- 추가 기능(필요할 때만 켬): 곡 구간 반복(기본 켬, 고른 마디만 되풀이하고 잘 불면 빠르기를 5씩 올림), 연습 목표와 달력(기록 탭에만 표시), 오늘의 연습 순서(정해 둔 연습을 차례로 열고 시간이 되면 알려 주기만 함).
- 반주 맞춰 녹음하기는 화면 위에 1·2·3 단계 안내를 두고, 반주를 하나만 불러오면 바로 녹음 화면으로 넘어갑니다. 폴더는 반주가 여러 개일 때만 보입니다.
- 내 곡 만들기(1.5): 피날레 같은 악보 프로그램처럼 음 길이(온음표·2분·4분·8분·16분·점·쉼표)를 고르고 오선의 줄이나 칸을 누르면 그 높이의 음이 적힙니다. 도~시 계이름 버튼과 옥타브 ▲▼로도 적을 수 있고, 이 팬플룻의 조에 맞춰 반음(예: 파#)이 저절로 붙습니다. ◀ ▶, 지우기, 되돌리기, 악상, 듣기를 지원하고, 곡 이름·빠르기·박자는 위의 ‘곡 정보’ 줄에서 정합니다.
- 홈 목록에서 연 메트로놈·음정 보기도 뒤로 가기로 홈에 돌아옵니다. 부점 리듬은 긴 칸·짧은 칸으로 나눈 리듬 막대로, 텅잉은 큰 글씨(정확해요·빨라요·늦어요)와 가는 막대로 보여 줍니다.
- 연습곡 51곡(저작권이 끝난 곡의 가락만): 민요, 찬송가(예수 사랑하심은, 다 찬양하여라, 다 감사드리세, 높은 하늘에서 등), 세계 명곡(오 수재너, 금발의 제니, 마이 보니, 민스트럴 보이, 애프턴 강 등), 클래식(보리수, 모차르트 K.545, 아이네 클라이네 나흐트무지크 등), 동요·쉬운 곡(메리의 어린 양, 쿰바야, 소나무야 등). 난이도는 막대 1~5개로 보여 줍니다.
- 연습 기록, 음정 습관, 기록 파일 보관
- 홈 화면 설치(기기별 안내), 전체화면, 화면 꺼짐 방지, 오프라인 실행
- 악보 파일 불러오기(1.6): 연습곡 → ‘악보 파일 불러오기’에서 ABC(.abc) 또는 MusicXML(.musicxml, .xml, .mxl) 악보를 불러와 ‘내 곡’으로 만듭니다. ABC 글을 붙여 넣어도 됩니다. 조표·임시표, 도돌이표와 1·2번 괄호, 셋잇단음표, 붙임줄, 못갖춘마디를 읽고, 화음이나 여러 성부가 있으면 맨 위 가락만 가져옵니다. 불러온 곡은 기기 안에만 저장됩니다.
- 음정 인식(1.6): 숨소리가 많이 섞여도 한 옥타브 낮게 읽거나 음이 높게 치우치지 않도록 고쳤습니다.
- 소리 지연 저장(1.6): 앱을 두 곳에 열어 두었을 때 한쪽에서 잰 소리 지연이 다른 쪽 때문에 ‘아직 안 잼’으로 되돌아가던 문제를 고쳤습니다.
- 글꼴(1.6): 글꼴을 `vendor/fonts/`에 넣어(쓰는 글자만 남긴 파일, OFL 라이선스) 인터넷 없이 처음 열어도 같은 모양으로 보입니다.
- 소리 맑기(1.7): 소리 정보 줄의 ‘소리 맑기’ 칸이 바람 새는 소리가 얼마나 섞였는지(맑아요 / 바람 샘 / 많이 샘) 보여 줍니다. 롱톤 결과에도 소리 맑기가 나오고, 바람이 많으면 입술 모양 안내를 합니다. 좁은 세로 화면에서는 이 칸 대신 ‘오늘’ 칸을 숨깁니다(오늘 연습 시간은 기록 탭에서 봄).
- 기준음(1.7): 음정 보기의 ‘기준음’ 버튼이나 음계·관 건너뛰기·곡 따라 불기·반음 꺾기·비브라토·롱톤 설정에서 켜면, 목표 음을 낮은 옥타브에서 계속 울려 귀로 맞추는 연습을 돕습니다.
- 숨 쉴 곳 표시(1.7): 쉼표 없이 길게 이어지는 곳에서 긴 음이나 마디 끝 뒤에 파란 숨표(’)를 답니다. 박자대로 불기 결과에서 음 중간에 소리가 끊긴 마디를 알려 줍니다.
- 자주 틀리는 마디(1.7): 곡을 불 때마다 마디별로 놓친 비율을 기억해 두었다가(최근 5번), 결과 줄과 곡 창에 ‘○~○마디 연습’ 버튼을 띄웁니다. 누르면 그 마디만 구간 반복합니다.
- 곡 반주(1.7): 가락을 보고 조(장조·단조)와 기본 화음을 찾아 낮은 화음 반주를 붙입니다. 박자대로 불기의 ‘반주 함께’, 곡 따라 불기의 ‘시범 듣기에 반주’에서 켭니다.
- 반주·기준음과 판정: 반주와 기준음은 가장 낮은 관보다 한 옥타브 넘게 낮은 순음으로만 울리고, 마이크 분석 앞에 그보다 낮은 소리를 걸러 내는 필터를 두어 스피커 소리가 마이크로 들어가도 음정 판정이 흔들리지 않습니다.
- 자동 점검: 저장소 맨 위 폴더에서 `node panflute/tools/check.js`를 실행하면 모든 화면 열기, 가짜 마이크로 연습 끝까지 진행, 음정 정확도, 반주·기준음이 섞일 때의 판정, 자주 틀리는 마디·끊김 안내, 설정 저장, 악보 불러오기를 확인합니다(`screens`·`practice`·`pitch`·`mix`·`weak`·`store`·`import` 중 하나만 고를 수도 있음).

## 다과비 계산기 (`snack-calc/`)

다과비처럼 정해진 예산 안에서 마트 간식을 고를 때 쓰는 휴대폰용 계산기입니다.
- 가격·개수(이름은 선택)를 넣으면 위쪽 목록에 쌓이고, 남은 금액과 예산 초과 여부를 바로 보여 줍니다.
- 가격을 입력하는 동안 "담으면 남는 잔액"과 "남은 돈으로 최대 몇 개"를 미리 보여 줍니다.
- 목록에서 개수 −/+, 품목을 눌러 수정, 삭제 후 되돌리기, '새로 시작'(두 번 눌러 전체 삭제)을 지원합니다.
- '− 할인' 버튼으로 할인(마이너스) 금액을 넣을 수 있습니다.
- 입력순·가나다순·금액순으로 정렬하고, 품목을 '보류'해서 합계에서 잠시 뺄 수 있습니다.
- '잔액 맞추기'를 누르면 개수 조정·보류 조합, 같은 가격으로 나눠 사기, 끝자리 맞추기를 제안하고 바로 적용합니다.
- 홈 화면 설치·전체화면·오프라인 실행을 지원하고, 입력 내용은 기기 안(localStorage)에만 저장합니다.

## 청년부 출석부 (`attendance/`)

청년부 명단과 주일예배 출석을 연도별로 관리하는 앱입니다. PC·태블릿·휴대폰에서 씁니다.
- 사람마다 출생연도를 저장하고, 위쪽 연도를 바꾸면 나이(한국식)와 구분(예비청년 · 1년차 · 2-5년차 · 6-10년차 · 11-14년차 · 15년차 이상)이 자동으로 바뀝니다. 구분 안에서는 나이순, 같은 나이는 가나다순입니다.
- 직업군인·군인·유학·장기결석 같은 특별 구분으로는 명단 탭에서 끌어다 옮깁니다(휴대폰은 꾹 누른 뒤 끌기).
- 출석 탭에서 이름을 누르면 출석 표시가 됩니다. 세로 스크롤 없이 위→아래로 채우고 오른쪽 칸으로 넘어가며, '이어보기'(구분 머리글을 끼워 빈칸 없이 이어서)와 '구분별'(구분마다 새 칸) 중에서 고릅니다. '지난주 출석자 먼저'를 켜면 구분 안에서 지난주 출석자를 앞으로 보여 줍니다.
- 인쇄: A4 한 장 출석부. '원래 양식'(구분별 칸, 예비청년 아래 1년차, 마지막 칸에 특별 구분)과 '붙여서'(이어서 채움) 중에서 고르고, 장기결석자는 뒷장에 따로 나옵니다.
- 엑셀 내보내기: 날짜별·월별 출석 통계, 개인별 출석 횟수·출석률·연속 결석, 구글 시트와 같은 모양의 월별 시트(예: 26.10), 명단.
- 엑셀 가져오기: 이 앱에서 내보낸 파일(명단까지 복원), 또는 구글 드라이브의 월별 출석 시트(시트 이름 '26.10' 모양, ○ 표시)를 읽어 출석 기록을 더합니다. 설정에서 구글 시트 주소로 .xlsx 파일을 바로 받을 수 있습니다.
- 명단은 개인 정보라서 이 저장소에 넣지 않습니다. 기록은 그 기기 안(localStorage)에만 저장되니 가끔 엑셀로 내보내 두세요.
- 홈 화면 설치·전체화면·오프라인 실행을 지원합니다. 외부 라이브러리(SortableJS, SheetJS)는 `attendance/vendor/`에 라이선스와 함께 들어 있습니다.

## 전도현황 (`evangelism/`)

주공 1단지·2단지 아파트 전도 기록을 동·호수별로 쓰고 보는 앱입니다. 집사님·권사님이 휴대폰으로 쉽게 쓰도록 큰 글씨와 버튼으로 만들었습니다.
- 로그인: 휴대폰마다 앱이 기기 번호를 만들어 저장합니다(브라우저는 휴대폰 고유번호를 읽을 수 없음). 처음 쓰는 휴대폰은 이름을 넣어 **승인 요청**을 보내고, 화면의 4자리 확인 번호를 마스터가 보고 승인하면 열립니다. 휴대폰을 바꾸면 같은 이름으로 다시 요청하고, 승인할 때 예전 기기를 끊을 수 있습니다.
- 마스터 모드: 구글 시트 '설정' 탭 B3의 마스터 암호를 넣은 기기가 마스터가 되어 다음부터 저절로 마스터로 열립니다(휴대폰을 바꿨을 때도 마스터 암호로 다시 들어옴). 마스터는 기기 승인·끊기·이름 바꾸기, 엑셀 불러오기, 담당자 고치기를 합니다. 승인을 기다리는 기기가 있으면 첫 화면에 알림이 뜹니다. 서버는 요청마다 보낸 기기가 승인됐는지, 마스터인지 검사하고, 쓴 사람 이름도 기기에 승인된 이름으로 남깁니다. 마스터 암호를 여러 번 틀리면 10분 동안 막힙니다.
- 동을 누르면 최근 두 회차(날짜·선물·함께 간 사람·만남/부재/거부 수)와 층별 호수가 **한 줄에 한 집씩** 나오고, 집마다 최근 기록 두 개가 보입니다.
- '오늘 전도 기록 시작하기'에서 선물(꽃·달력…)과 행사만 고르면 날짜·회차 번호(동별로 이어서)·작성자가 자동으로 들어갑니다. 구글 시트가 늦게 답해도 3초 넘게 기다리지 않고 바로 시작합니다. 그다음 집을 누르고 [만나서 전달]·[문앞에 두고 옴]·[부재]·[거부]와 한 줄 메모만 넣으면 됩니다.
- 집을 누르면 구분(대상·특별대상·교인·장기결석·거부·부재·다른 교회·성당·이사) 바꾸기, 심방대상 표시, 기본 메모(이름·연락처), 지난 기록 전체가 나옵니다.
- 구분별 보기, 심방대상 목록, 찾기(호수·이름·전화·내용), 최근 기록이 있습니다.
- 목록 뽑기·인쇄: 동·구분·최근 결과·심방대상으로 골라서, 보여 줄 정보(구분·심방·기본 메모·마지막 방문 날·횟수·최근 기록 몇 개)와 정렬(층 순서, 구분 순서, 오래 안 간 집 먼저, 많이 다녀온 집 먼저, 최근 결과 순)을 정해 한 줄씩 표로 보고 A4로 인쇄하거나 엑셀로 받습니다. 동마다 구분별 세대 수 요약과 색 띠가 붙고, 동마다 새 장에 인쇄할 수도 있습니다.
- 엑셀 받기(현황표·심방대상·전체 기록·동별 시트), 고친 기록(누가 언제 무엇을 고쳤는지, '되돌리기').
- 사용법 둘러보기: 연습용 자료(901·902동)로 처음부터 따라 해 봅니다. 빛나는 곳만 눌리고, 예시 입력도 해 보지만 아무것도 저장·전송되지 않습니다. 중간에 '그만하기'로 끝낼 수 있습니다. 처음 들어올 때 한 번 권합니다.
- 화면 색: 밝게(기본)·어둡게·기기 설정대로. 글자 크기 3단계.
- 원래 엑셀(동별 시트, 한 칸에 "14.부재 15.거부 …"로 이어 쓴 결과)은 마스터의 '원래 엑셀 불러오기'로 회차별 기록으로 나눠 넣습니다. 번호 앞에 적힌 이름·연락처는 기본 메모가 됩니다.
- 자료 저장: 주민 이름·연락처가 들어 있어서 이 저장소에는 넣지 않습니다. 교회 구글 시트(Apps Script, `evangelism/server/Code.gs`)에 저장하고, 앱은 기기 안(IndexedDB)에도 저장해 두어 인터넷이 끊겨도 보고 쓸 수 있습니다(연결되면 자동으로 보냄). 서버 코드를 바꾸면 Apps Script에서 setup 실행 후 '배포 관리 → ✏️ → 버전: 새 버전'으로 다시 배포해야 합니다.
- 초대: 마스터 설정의 초대 링크(`?s=서버주소`) 또는 초대 QR. QR을 휴대폰 카메라로 찍으면 카카오톡을 거치지 않고 크롬·삼성 인터넷·사파리로 바로 열립니다. 카카오톡 안 브라우저는 크롬과 저장 공간이 따로라서, 카카오톡 안에서 열리면 곧바로 기본 브라우저로 넘기고(서버 주소를 그대로 넘김), 넘어가지 않으면 "크롬으로 열기" 단추와 "그냥 카카오톡에서 쓰기"를 보여 줍니다.
- 홈 화면 설치·전체화면·오프라인 실행을 지원합니다. 외부 라이브러리(SheetJS, qrcode-generator)는 `evangelism/vendor/`에 라이선스와 함께 들어 있습니다.

## 반주 반복기 (`hymn-loop/`)

미가엘 반주 같은 찬양 반주(MR) 영상을 열면 전주·절·후주를 소리로 찾아서, 마지막 절이 끝나기 직전에 1절 시작으로 넘어가 계속 반복하는 앱입니다.
- 자동 인식: 소리를 12음 특징으로 바꿔 같은 반주가 한 절 길이만큼 떨어져 되풀이되는 곳을 찾습니다(2절·3절·4절, 전주가 없는 반주 포함). 연주 속도가 조금씩 흔들려도 넘어가는 바로 그 부분의 박자를 1/1000초 단위로 다시 맞춥니다. 영상이 있으면 절이 바뀔 때 가사 화면이 넘어가는 순간을 찾아, 소리가 똑같이 되풀이되는 범위 안에서 넘어가는 곳을 그때로 옮겨 가사 화면도 제때 바뀌게 합니다. 1절뿐이라 찾지 못하면 곡 전체를 반복하고 직접 정하도록 안내합니다.
- 소리는 Web Audio로 넘어갈 곳을 미리 예약해서 끊김 없이(0.03초 겹침) 이어 주고, 영상은 소리에 맞춰 따라갑니다. 화면이 꺼져도 정확히 넘어갑니다.
- 재생바 위에 전주·1절·2절…·후주를 나눠 보여 주고, 절 이름을 누르면 그 절 처음으로 갑니다. 재생바는 스피커·블루투스 지연을 빼고 실제로 들리는 위치를 보여 줍니다.
- 재생할 절(카세트 버튼): 전체 / 1절 / 2절 …. 전체를 누르면 나머지가 올라오고, 절 버튼은 하나씩 눌렀다 뺄 수 있어 누른 절만 차례로 반복합니다. 바꾸면 지금 절이 끝난 다음부터 적용되고, 절마다 박자를 맞춰 둔 경계에서 넘어가 어느 절로 가도 자연스럽습니다.
- "이번 절 끝나면 후주로 마치기"를 누르면 그 절이 끝나고 후주가 나온 뒤 멈춥니다. 다시 누르면 계속 반복합니다.
- 마치기 예약: 타이머(시간·분 고르고 시작, 남은 시간 표시)와 반복 횟수(숫자 넣고 시작, 몇 번째·남은 횟수 표시) 중 하나를 탭으로 골라 씁니다. 시간이 다 되거나 정한 횟수를 다 돌면 그 절까지 하고 후주로 마친 뒤 앱을 닫습니다(설치한 앱 창은 닫히고, 닫을 수 없는 곳에서는 안내만 띄움). "예약대로 마치면 앱도 닫기"는 끌 수 있습니다.
- 반복 구간 맞추기(파형): 끝 주변(위)과 시작 주변(아래)의 소리 세기·박자를 같은 시간 눈금으로 마주 보게 그리고, 가운데 빨간 선이 넘어가는 곳입니다. 0.1·0.01초 단추나 파형을 손가락으로 끌어 위아래 박자가 같은 자리에 오게 맞추고, "시작을 끝 박자에 자동 맞추기"로 한 번에 맞출 수도 있습니다. 재생과 상관없이 맞출 수 있고 곡마다 기억합니다.
- 🖥 다른 모니터에 띄우기(PC 크롬·엣지): PPT 발표자 보기처럼 고른 모니터에 영상만 있는 창을 띄우고, 원래 창에서 조작합니다. 띄운 화면은 소리에 맞춰 따라가고, 두 번 누르면 전체화면입니다.
- 💾 저장하기
  - 🎬 영상 파일(mp4): 전주·후주를 넣을지, 넣을 절, 반복 횟수를 골라 이어 붙인 mp4를 만듭니다. 이어 붙인 곳은 소리를 0.012초 동안 부드럽게 바꿔 매끄럽고, TV·USB·휴대폰 어디서나 그냥 재생됩니다. 인코딩은 브라우저(WebCodecs)와 Mediabunny(`vendor/mediabunny.min.js`, MPL-2.0, 라이선스 `vendor/mediabunny-LICENSE.txt`)로 하며, 크롬·엣지는 저장할 곳을 먼저 골라 곧바로 파일에 씁니다.
  - ♾ 무한 반복 파일(html): 영상과 반복 구간을 html 파일 하나에 담습니다. 이 파일만 옮기면 인터넷 없이 아무 컴퓨터에서나 열고 ▶을 한 번 누르면 전체화면으로 고른 절이 끝없이 반복되고, "후주로 마치기"로 끝냅니다(앱 설치나 조작할 사람이 필요 없음).
- 연 영상은 그 기기 안(IndexedDB)의 "내 반주 목록"에만 저장되고 인터넷에 올리지 않습니다.
- 홈 화면 설치·전체화면·화면 꺼짐 방지·오프라인 실행을 지원합니다.
