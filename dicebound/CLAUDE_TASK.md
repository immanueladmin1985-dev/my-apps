# Claude Code 개발 지침 — DICEBOUND

당신은 이 프로젝트의 게임플레이 프로그래머입니다. 기존 코드를 먼저 읽고, 동작하는 기능을 보존하면서 작은 단위로 개선하세요. 현재 프로젝트는 순수 HTML/CSS/JavaScript이며 빌드 도구가 필요하지 않습니다.

## 게임 비전
- 킹덤 컴의 주사위 미니게임에서 영감을 받은 주사위 눈 선택/보존/재굴림
- 발라트로에서 영감을 받은 족보 시너지, 특수 주사위, 유물
- 로그라이크 분기 맵, 일반/정예/보스, 상점/보물/휴식/이벤트
- 브라우저 기반 싱글 플레이

## 현재 구조 (2026-10 리디자인 이후)
- 규칙 계산은 `js/rules.js`(순수 함수), 상태 변경은 `js/game.js`, 화면은 `js/ui.js`에만 둔다.
- 미리보기와 실제 공격은 같은 `computeAttack` 결과를 쓴다.
- 이미지 경로는 `js/data.js`의 `DB.IMG`와 각 정의에서만 관리한다.
- 변경 후 `tests/rules.test.js`, `tests/sim.js`, `tests/e2e.js`를 실행하고, 파일을 추가했다면 `tools/make_sw.py`로 캐시 버전을 올린다.

## 게임 규칙
- 플레이어는 기본 주사위 5개, 체력 50, 골드 20으로 시작한다. 특수 주사위는 기본 주사위와 교체한다.
- 턴이 시작되면 주사위 5개를 자동으로 굴리고, 이후 고른 주사위만 턴당 2회까지 다시 굴린다.
- 족보는 확정된 5개 주사위 결과로 판정한다.
- 족보는 가장 강한 항목 하나만 기본 공격으로 사용한다.
- 기본 족보: 하이 카드, 원 페어, 투 페어, 트리플, 스트레이트(1-2-3-4-5 또는 2-3-4-5-6), 풀하우스, 포카드, 파이브 오브 어 카인드.
- 적은 행동을 예고한다. 플레이어 공격 후 살아 있으면 적이 행동한다.
- 일반 적보다 정예가 어렵고, 정예는 더 좋은 보상을 준다.
- 어떤 맵 경로를 골라도 마지막 보스에 도달할 수 있어야 한다.

## 개발 원칙
- 중요한 규칙을 구현하기 전에 짧은 계획을 제시한다.
- 기존 동작을 유지하고 수정 범위를 명확히 한다.
- 임시 UI를 조용히 삭제하거나 주요 기능을 생략하지 않는다.
- 난수 생성은 테스트 가능하도록 주입할 수 있는 구조를 선호한다.
- 효과 처리 순서와 중첩 규칙을 문서화한다.
- 변경 후 수동 테스트 절차를 적는다.
- 구현하지 않은 기능은 구현했다고 말하지 않는다.
